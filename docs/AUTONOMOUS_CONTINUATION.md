### Phase B — Graphic novel content and experience hardening

1. Produce a concise single review package (overview, evidence, desktop/mobile screenshots, exact test commands/results, known limitations, screenplay gaps, asset rights/provenance).
2. Recommend whether the provisional graphic novel is *ready for an owner preview*, not whether final screenplay or art is approved.
3. Leave one clear next owner decision or blocker. Do not prolong development for minor cosmetic perfection.

## Autonomous working rules
- Codex may split or combine internal phases, select lower-risk fixes, run iterative implementation/QA cycles and push checkpoints to the existing branch.
- Stop and escalate ONLY if continuation would need a material change of story, characters, art direction, scope or standards; inaccessible essential inputs; external expenditure/services; security/privacy concerns; or production release.
- For missing original screenplay and final sphere illustration, use explicit gap documentation and continue independent safe tasks. These are **deferred content limitations**, not a reason to abandon work or substitute fabricated canon.
- Bound iteration: maximum **three self-directed implementation/review passes** after initial assessment. If the same class of defect fails twice, stop that subtask, record the blocker and continue unrelated safe tasks. No infinite polishing loop.
- Honor $0 incremental budget. Avoid automated events, unattended GitHub-triggered loops, new agent orchestration infrastructure, or changes to global game-development-standards as part of this project mandate.
- Preserve M1/M2 behavior, nine-ending graph, tests and accepted appearance. No wholesale restructuring or unapproved art/video campaigns.
- Prefer durable GitHub branch pushes with concise history, QA evidence and up-to-date `PROJECT_STATE.md`. Keep draft PR #1 open for owner review.
- Never merge `main`, deploy Pages, change Possibility, declare final production acceptance, or make a public release.

## Handoff target
On completing all feasible approved tasks, Codex submits **one consolidated report** with exact commit, QA evidence, open gaps and owner-level choices. Intermediate messages are optional and should not require a human reply. This mandate authorizes work **inside a Codex task once given to Codex**; a GitHub document/comment does not autonomously awaken the agent.
